# MDevolved

MDevolved gives AI coding agents one durable, owner-controlled Project memory
across computers, apps, CLIs, and orchestration harnesses. The CLI connects a
normal Markdown folder as a Source; Obsidian is optional.

```sh
npx mdevolved@latest sync ./your-project
```

The command prints the next pairing action and keeps local custody material on
the device. MDevolved stores durable Project identity, bounded context,
preferences, inert reusable skills, cited outcomes, checkpoints, reviews, and
recovery evidence. It does not replace your coding harness, schedule agents,
capture transcripts or hidden reasoning, or inherit filesystem authority.

## Six actions to your first durable resume

1. **Deploy or open MDevolved.** Deploy Community into your Cloudflare account,
   or open the MDevolved workspace you were invited to.
2. **Claim it with a passkey.** Create the owner passkey that controls Sources,
   agents, recovery, and revocation.
3. **Connect one disposable Markdown folder.** In that test folder, run
   `npx mdevolved@latest sync .` and approve only that Source.
4. **Authorize one compatible agent.** Approve its exact Source and folder
   boundary. You can revoke it at any time.
5. **Connect the Project.** In that agent, say **Connect this project to
   MDevolved** and keep working normally.
6. **Resume in a fresh session.** Open a fresh authorized session, say
   **MDevolved resume project**, and verify that the objective, evidence, useful
   failure, and next action return.

New connections use the MDevolved identity. Existing alpha connections and
stored OWD-compatible records remain supported through explicit compatibility
adapters; no migration restores or copies grants, credentials, sessions,
OAuth state, actors, leases, or live authority.
