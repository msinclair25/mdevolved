# MD5 acceptance test matrix

This matrix ties each MDevolved brand-transition requirement to executable
evidence. Static copy checks are a guardrail only; they never substitute for
the runtime suites below.

| Requirement                                                 | Executable evidence                                                                                                                                                                                                                                                                                                                                                                       |
| ----------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| New and legacy navigation/deep links                        | `apps/web/test/workspace-navigation.test.ts` exercises `#sources`, legacy `#vaults`, current sections, and unknown hashes; `e2e/phase8-foundation.spec.ts` exercises navigation state in Chromium and narrow Chromium.                                                                                                                                                                    |
| New and legacy resume instructions                          | `apps/worker/test/agent-access.test.ts` reads live MCP initialize instructions and requires both phrases; `project-context-policy.test.ts` and client-pack tests require both phrases in generated policy packs.                                                                                                                                                                          |
| Folder and Obsidian onboarding                              | `pnpm test:md5:acceptance` runs folder-adapter, CLI, desktop, Obsidian-plugin, Worker readiness, and web onboarding suites; full browser E2E exercises the state-aware owner path.                                                                                                                                                                                                        |
| Source-neutral normal-path terminology                      | `scripts/md5-brand-transition.test.mjs` inventories App, Agent authorization, Project initialization, Collaboration, Backup, Restore, Snapshot, Snapshot Restore, and marketing copy. Full `e2e/phase8-foundation.spec.ts` exercises the changed runtime labels, pairing hrefs, disabled-state controls, restore actions, and narrow layout rather than relying on static matching alone. |
| Pairing links and plugin identity                           | Browser E2E asserts additive `mdevolved:` and legacy `obsidian://owd-pair` hrefs; `packages/obsidian-plugin/test/pairing-contract.test.ts` exercises accepted and denied `owd-pair` shapes; release checks freeze plugin ID, settings, archive, tag, BRAT, and updater paths.                                                                                                             |
| Backup, export, snapshot, and restore                       | Worker backup/snapshot tests exercise current and legacy formats, staged restore, authority quarantine, and source descriptors; web archive/restore tests and narrow browser restore preserve existing filenames and manifests.                                                                                                                                                           |
| Old/new capability behavior                                 | Worker source-descriptor, pairing, source-device, MCP, and compatibility tests cover legacy clients without descriptors and current clients with negotiated folder/Obsidian capabilities.                                                                                                                                                                                                 |
| Accessibility, narrow width, and rapid-selection continuity | Full Playwright E2E runs all 74 cases in `chrome-desktop` and `chrome-narrow`; focused tests cover keyboard/ARIA regions, restored focus, rapid selection, background refresh, and mounted form continuity.                                                                                                                                                                               |
| Marketing artwork and visible brand                         | `scripts/md5-brand-transition.test.mjs`, marketing tests, and release-contract checks require exact `MDevolved`, the MD5 artwork, and Source terminology.                                                                                                                                                                                                                                 |
| Recovery-key guidance                                       | Web recovery tests exercise generated `mdevolved-recovery-key-*` names and parsing of existing age identity files; MD5 contract checks require legacy names to be labeled compatibility-only.                                                                                                                                                                                             |
| Installer, update, deploy, and package metadata             | Plugin installer tests, plugin production packaging, desktop manifest tests, marketing tests, `release:check`, and dry-run deploy gates freeze old update identities while using current repository/deploy links.                                                                                                                                                                         |
| Legacy GitHub repository URL                                | `gh repo view msinclair25/owd-platform` resolves to API identity `mdevolved`; redirect-following uncached checks return HTTP 200 at the renamed repository for the old root, `/tree/main/docs`, and `/blob/main/README.md`.                                                                                                                                                               |

The exact-candidate repository gate remains the sequence in
[`QUALITY-GATES.md`](QUALITY-GATES.md), including the complete unit/service
suite, full browser suite, builds, deployment dry-runs, and public-source check.
