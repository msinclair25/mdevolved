Deploy Community, connect one Source, and authorize the agent you already use. MDevolved handles routine continuity from there.

  1. 01

    Deploy MDevolved Community

    Use the one-click path to create the owner-controlled data plane in your Cloudflare account, then claim it with a passkey.

    Your workspace
  2. 02

    Choose a Markdown folder or Obsidian

    Run npx mdevolved@latest sync . for a folder, or use the optional compatibility-preserving Obsidian adapter. Only the Source you approve is connected.

    Your files
  3. 03

    Connect the agents you choose

    Add MDevolved as a standard MCP server and authorize each client for one exact Source and optional folders. Every grant is distinct, scoped, expiring, and immediately revocable.

    Your boundary
  4. 04

    Connect the Project once

    Say “Connect this project to MDevolved.” The agent creates, joins, or resumes the exact Project without a copied prompt or manual Project ID.

    Your choice
  5. 05

    Keep working in the agent

    The agent resumes, retrieves targeted evidence when needed, and checkpoints verified progress before it finishes.

    Agent-first
  6. 06

    Resume anywhere

    Open another compatible agent, session, orchestration, or computer and say “MDevolved resume project.” Start from the durable Project tip, not from zero.

    Your record
